Demo Flow · 5 min

给评委的演示动线五分钟看完所有亮点

  1. 个人中心建档：昵称 + 身份选「竞赛选手」，右侧资料卡即时更新
  2. 知识图谱：搜「蓝桥杯」织出知识网格 → 点节点换中心 → 加入学习清单 → AI 排周计划
  3. 论坛发帖：写一篇经验帖，回图谱看它长出新节点
  4. 情报官：拉取学校官方通知 → 点「AI 一句话」看溯源摘要 → 点标题跳原文
  5. 安全雷达：粘一段 HR 聊天记录，看四跳链路 + 编号证据 + 法条原文

清空后去情报官/图谱/个人中心刷新，徽章会从「Redis 缓存命中」变成「查 MySQL 并回填缓存」，再刷一次又变回命中——这就是赛题要求的缓存策略，肉眼可验。

AI Engine · Degrade by Design

AI 引擎说明降级是特性，不是缺陷

.env 未配置 MAAS_API_KEY 时，全链路自动降级为本地规则引擎：通知摘要、三元组抽取、风险判级、周计划理由一步不少，断网也能完整演示。每个结果的引擎标签（大模型 / 本地规则）都如实标注。
拿到华为云 MaaS 的 Key 填进 .env 即切换大模型，代码零改动，页面标签自动变为「大模型」。
安全雷达的证据纪律不受引擎影响：判级和置信度由代码计算、检索决定引用哪条法条、大模型只负责把话说成人话且只能引用喂给它的条款——条款库里没有就明说弃权。
